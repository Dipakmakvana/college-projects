# College Projects

A collection of practical software projects built for college work and independent practice. Each project has its own folder with the source code and instructions.

## Projects

### School Subjects Manager — Python

A command-line app for managing a personal list of school subjects.

- Add, remove, and display subjects
- Prevent blank or duplicate names, including differences in capitalization
- Save the list between runs in a local JSON file
- Uses Python's standard library; requires Python 3.8 or newer

[Open the project guide](school-subjects-manager/README.md) · [View the Python source](school-subjects-manager/school_subjects_manager.py)

## Run the app

Open a terminal in the project folder and run:

```sh
python school_subjects_manager.py
```

See the [project guide](school-subjects-manager/README.md) for details.
